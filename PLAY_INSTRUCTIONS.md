1. Go to: https://github.com/qgao1-sudo/lab/blob/claude/gh-pages-011CV3MYZzFhafMcLC25BEcr/play-now.html
2. Click the "Download raw file" button (or press Ctrl+S to save)

### Step 2: Open and play
- Double-click the downloaded file
- OR drag it into your browser
- Start mixing potions!

## 🌐 GitHub Pages (Permanent URL)

To get a permanent, easy-to-remember URL:

1. **Enable GitHub Pages:**
   - Visit: https://github.com/qgao1-sudo/lab/settings/pages
   - Under "Build and deployment" → "Source"
   - Select **"GitHub Actions"**
   - Click Save

2. **Wait for deployment:**
   - Check progress at: https://github.com/qgao1-sudo/lab/actions
   - Wait for green ✓ (1-2 minutes)

3. **Your game URL:**
   ```
   https://qgao1-sudo.github.io/lab/play-now.html
   ```

## 🎯 Game Features

### Chemical Reactions:
- 💥 **Red + Blue** = MASSIVE EXPLOSION (300 particles!)
- 🫧 **Red + Yellow** = BUBBLING (growing bubbles!)
- ❄️ **Blue + Yellow** = FROZEN (50 ice crystals!)
- 🍮 **Green + Red** = JELLY (intense wobble!)
- ✨ **Pink + Green** = GLOWING (bright pulses!)
- 🍯 **Pink + Yellow** = VISCOUS (dripping effect!)

### Controls:
- Click **🧪** to add beakers (up to 6)
- Select a potion from the left panel
- Click on a beaker to pour
- Switch between 💧 dropper and 🫗 pour tools
- Mix different potions to see reactions!

## ❓ Troubleshooting

**Link shows code instead of game?**
- Use the HTML Preview or RawGit links above
- OR download the file and open it locally

**Game doesn't load?**
- Make sure you have internet connection (for Three.js library)
- Try a different browser (Chrome or Firefox recommended)
- Check if JavaScript is enabled

**GitHub Pages not working?**
- Make sure you selected "GitHub Actions" as the source
- Wait a few minutes after enabling
- Check the Actions tab for deployment status
