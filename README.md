# 🧪 化学实验室模拟器

一个使用 Three.js 构建的逼真3D化学实验室模拟游戏，具有真实的液体物理效果和多种化学反应。

## ✨ 功能特性

### 🎨 五种药水
- **红色药水** - 基础化学试剂
- **蓝色药水** - 冷却剂
- **黄色药水** - 活性溶液
- **粉色药水** - 催化剂
- **绿色药水** - 中和剂

### 🧬 化学反应系统

不同液体混合会产生以下反应：

| 混合组合 | 反应效果 | 结果颜色 |
|---------|---------|---------|
| 红色 + 蓝色 | 💥 爆炸反应 | 紫色 |
| 红色 + 黄色 | 🫧 产生气泡 | 橙色 |
| 蓝色 + 黄色 | ❄️ 冻结成冰 | 青色 |
| 粉色 + 黄色 | 🍯 变成粘稠物 | 琥珀色 |
| 绿色 + 红色 | 🍮 凝固成果冻 | 黄绿色 |
| 绿色 + 蓝色 | 🫧 冒泡反应 | 天蓝色 |
| 粉色 + 蓝色 | ⚪ 无明显反应 | 紫红色 |
| 粉色 + 绿色 | ✨ 发光反应 | 荧光绿 |
| 红色 + 绿色 | 🍯 变粘稠 | 棕色 |
| 黄色 + 绿色 | 🍮 凝固 | 柠檬绿 |

### 🛠️ 工具系统
- **倾倒工具** (🫗) - 快速倒入大量液体
- **滴管工具** (💧) - 精确控制液体添加量

### 🎮 游戏特性
- **无限烧杯** - 点击左下角"+"号可添加多个烧杯（最多6个）
- **真实物理** - 液体具有重力、波动和粘度效果
- **粒子系统** - 倾倒时的液滴动画
- **光照效果** - 动态点光源和阴影
- **交互反馈** - 反应时的震动、爆炸、气泡等视觉效果

## 🚀 如何使用

### 启动游戏
1. 在浏览器中打开 `index.html`
2. 确保浏览器支持 WebGL

### 操作指南
1. **添加烧杯**：点击左下角的🧪图标
2. **选择药水**：点击底部药水栏中的任意药水
3. **倒入液体**：点击烧杯将选中的药水倒入
4. **切换工具**：点击右侧的工具图标切换倾倒/滴管模式
5. **观察反应**：混合不同药水观察化学反应

### 最佳体验建议
- 先在一个烧杯中尝试不同的药水组合
- 观察每种反应的独特视觉效果
- 使用多个烧杯进行平行实验
- 尝试添加第三种液体看看会发生什么

## 🎨 视觉效果

### 逼真渲染
- **玻璃材质** - 透明度、折射和反射效果
- **液体材质** - 半透明流体效果和表面张力
- **实验室环境** - 木质桌面、墙壁、货架
- **动态光照** - 环境光、点光源、聚光灯、阴影

### 特效系统
- **爆炸效果** - 粒子四散、烧杯震动
- **气泡效果** - 持续上升的气泡流
- **冰冻效果** - 晶体生成和光泽
- **粘稠效果** - 液体流动减慢
- **果冻效果** - 晃动和弹性变形
- **发光效果** - 动态点光源脉动

## 🔧 技术栈

- **Three.js** (r128) - 3D渲染引擎
- **原生 JavaScript** - ES6+ 面向对象编程
- **HTML5 & CSS3** - 现代化UI界面
- **WebGL** - 硬件加速渲染

## 🎯 核心代码结构

### ChemistryLab 类
- `init()` - 初始化 Three.js 场景
- `setupLighting()` - 配置光照系统
- `createLabEnvironment()` - 创建实验室环境
- `createBeaker()` - 生成烧杯3D模型
- `addLiquidToBeaker()` - 添加液体
- `checkReactions()` - 检测化学反应
- `triggerReaction()` - 触发反应效果
- `createExplosion()` - 爆炸粒子效果
- `createBubbles()` - 气泡生成系统
- `createFreezeEffect()` - 冰冻效果
- `animate()` - 主渲染循环
